# Lost-FoundAI

Objective of this project is to build a low-cost smart voice assistant to locate misplaced belongings. By leveraging readily available technologies and addressing practical considerations, develop a valuable tool with diverse applications across various industries. Some of the industry applications are given below:
Inventory Management: Track and locate tools/items/equipment in workshops, hospitals, warehouses, or retail stores.
Asset Tracking: Monitor the location of valuable assets like art, jewelry, or medical equipment.
Child Safety: Provide real-time location tracking for children or pets within a designated area.
Senior Care: Assist seniors with memory/vision impairments by locating their belongings or offering reminders.
This project aims to expand the capabilities of VAs beyond basic functions. Learners will implement features like timekeeping, date/day display, and LLM-powered question-answering while integrating groundbreaking computer vision technology. This will allow the VA to track down misplaced belongings, making it a versatile and helpful tool for forgetful individuals and busy professionals.
